# 模型对比报告

> 数据：`generate_data.py` 生成的 5000 条模拟电商用户数据（分布假设见 README），8 个特征，训练/测试 8:2 划分（`random_state=42`）。运行 `python churn_prediction.py` 可复现。

## 结果

| 模型 | 测试集 AUC | 说明 |
|------|-----------|------|
| 逻辑回归 | **0.88** | 三者最高 |
| 随机森林 | 0.87 | 接近 |
| XGBoost | 0.85（实测 0.847） | 略低 |

## 为什么逻辑回归在模拟数据上胜出

数据由线性组合规则加噪声构造（见 `generate_data.py` 的 `churn_prob`），特征与标签之间线性关系强：
- 树模型靠分裂点逼近边界，样本量 5000 时对线性边界的拟合效率低于逻辑回归；
- 逻辑回归直接学习线性决策面，参数少、方差小，在这个数据分布上占优。
真实电商数据非线性与交互更多，XGBoost 通常反超——这也是对比实验的价值：**模型没有绝对优劣，要看数据结构和可解释性需求**。

## 类别不平衡的处理

- 流失标签由阈值构造（`churn_prob > 0.3`），非平衡分布；
- 评估不使用准确率（多数类基线会虚高），以 **AUC + 召回率**为主；
- 业务上误报成本低（多触达一个未流失用户）、漏报成本高（流失才发现），阈值向召回倾斜。

## 复现

```bash
pip install -r requirements.txt
python generate_data.py
python churn_prediction.py
```
